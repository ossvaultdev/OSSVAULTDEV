# DATA MANAGEMENT ENGINEERING
# OSS VAULT DEV

## 1. DÉFINITION:
OSS : Operating Secure System VAULT : Coffre fort  DEV : Développement

## 2. DESCRIPTION: 
C'est un logiciel qui à plusieurs fonctionnalités, qui permet d’avoir tout les usages utilisateurs qui lui permettent de créer puis gérer des données et aussi de créer des programmes ainsi que des bases données et d’établir des communication de données hautement cryptés entre utilisateurs dans un seul software et dans un environnement hautement sécurisé. L’utilisateur est le seul propriétaire de son environnement car tout ce logiciel est développé uniquement avec CORE .Net 10 de Microsoft. Il ne peut pas être copié, car il a un système de licence sophistiqué et encrypté pour son utilisation et l’ensemble des paramètres de l’utilisateur sont cryptés avec sa propre signature unique de sa licence d’utilisation. Ce qui donne que les données et programmes de l’utilisateur ne peuvent en aucun cas être lues ou être utilisées par un autre utilisateur avec ce même logiciel.
